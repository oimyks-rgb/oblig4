# docs

Requirements and models from the Claude Cowork lab, used as input for building Ekte Mat Online.

| Folder | Contents |
|---|---|
| `requirements/` | `EkteMat_backlog_v2.xlsx` is the backlog: stakeholders, 39 user stories (US-xx) in 7 epics, non-functional requirements (NFR-xx), conflicts and open questions (Cxx). `backlog.md` is a Markdown export of the same sheets so they can be read and searched without Excel. |
| `models/` | UML (use case, domain class, order state machine, recurring-lunch sequence) as PlantUML `.puml` with rendered `.png`; AS-IS and TO-BE order process as BPMN 2.0 (`.bpmn`, `.svg`, `.png`); the as-is process description, the problem-to-user-story table, and the model consistency report (violations V1-V4). |
| `plans/` | Agreed plans for larger features, written in Claude Code plan mode before building. |
